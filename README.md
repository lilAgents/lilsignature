# lilSignature

Build a clean, Gmail-safe HTML email signature with your details, links, and logo, then copy it in one click. A free tool by [lilAgents](https://lilagents.com).

**Live version:** https://lilagents.com/tools/signature/

This is the standalone, open-source build, a self-contained Astro site. The canonical hosted version is folded natively into the lilAgents website.

## Run locally

```
pnpm install
pnpm dev
pnpm build    # -> dist/
```

## Tech

Astro + Tailwind CSS + vanilla JS. 100% client-side; no backend, no API keys.
